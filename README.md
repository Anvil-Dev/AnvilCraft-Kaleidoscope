# AnvilCraft: Kaleidoscope

---

Added compatibility for the AnvilCraft mod with the _Kaleidoscope_ series. After installing this mod, you can:
- Use hoppers to input items into millstone, stockpot, and pot
- Use hoppers to output products from pot
- Squeeze dolls from _Kaleidoscope: Dolls_

This mod also adds the following content:
- Custom dolls:
    - XeKr's doll
    - Gugle's doll
    - _AnvilCraft_ part contributors' dolls
    - _AnvilCraft_ part supporters' dolls

---

为铁砧工艺添加了关于《森罗物语》系列模组的兼容，安装此模组后，你可以：
- 使用溜槽向石磨、汤锅、炒锅输入物品
- 使用溜槽从炒锅输出产物
- 把《森罗物语：玩偶》中的玩偶拍扁

本模组还添加了以下内容：
- 自定义玩偶：
    - XeKr 的玩偶
    - 古镇天的玩偶
    - 《铁砧工艺》部分贡献者的玩偶
    - 《铁砧工艺》部分支持者的玩偶
